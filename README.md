# Devin Review Automation Test Project

This is a minimal Node.js project for testing the Devin Review automation kit.

## Commands

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

The GitHub automation files are generated by the local `devin-review-automation` init CLI.

## Smoke Test

This branch is used to verify that the reusable Devin automation workflow runs on pull requests.
